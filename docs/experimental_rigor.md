# Experimental rigor

Three protocol failures were discovered and excluded rather than interpreted:

1. Synthetic states were incorrectly used as substitutes for trajectories generated by real opponents. These do not validate partner adaptation.
2. Off-grid optimizer outputs were counted as valid actions. Invalid optimizer-time actions are action-support or execution failures, not evidence about the reward method.
3. A cross-model representation comparison had serializer-dependent output validity. It was invalidated; a constrained, serializer-neutral interface was required for the later valid null result.

Valid studies use frozen manifests, disjoint train/validation/test opponent support, pinned model revision hashes, exact semantic reconstruction, reward parity checks, strict validity and fallback reporting, opponent-stratified episode bootstrap intervals, and competence gates declared before treatment exposure.

The public summaries omit invalid, withdrawn, protocol-bug, and obsolete unmatched runs. Frozen aggregate values are transcribed into small reviewable CSVs; provenance is documented separately.
